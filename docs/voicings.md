# 指法选择规则

v0.7.0 将指法限制为常见开放和弦、E/A 型可移动按法，以及限定的转位、半减七按法。C、G、D 开放形不再直接整体平移；只裁掉低音端的弦且必须保留指定低音和必要和弦音。

每个候选必须满足：

- 最多四个按弦手指，不依赖拇指绕颈。
- 最多一个横按；横按路径不能压住应当开放或更低品位发声的弦。
- 按弦范围最多四个相邻品位（最高品减最低品不超过 3），最高到第 12 品。
- 和弦三音／挂留音、七音及指定低音正确；可以省略纯五音。
- 播放使用与图示完全相同的弦位；× 弦不发声。
- 旧存档中不在新候选库的手动指法自动失效，改选当前合法候选。

默认低把位偏好仍考虑跨度与按指数量。“少横按”偏向开放与紧凑按法。横按以图中横线及下方文字说明。

这套约束和限定库排除了理论拼音式的大跨度指法，但不等于所有人都能立即按响。手型、琴颈宽度和熟练程度仍有差异；初学者可以切换“少横按”或另一个把位。

自动检查覆盖七个可选调、六种进行、全部丰富手法及目标，检查全部候选的音高、必要和弦音、手指数、跨度和横按条件。当前共有 216 个不同的和弦／弦位组合通过；未宣称已逐个进行真人试弹。

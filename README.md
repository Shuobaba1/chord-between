# 和弦之间

简约的离线吉他学习工具。下载整个项目后，直接用浏览器打开 **index.html** 即可使用，不需要安装依赖或联网。

## 当前功能

- 1645、4536251、顺阶下行低音（Leading Bass）练习；C、D、E、F、G、A、B 大调。
- 七和弦、副属和弦、构建 ii–V–I、挂留和弦、借用小四级；常见目标用星标提示。
- 和弦指板图、真实弦位发声、开放／紧凑／封闭按法选择。
- 尼龙吉他、木吉他、电钢琴三种合成音色；四种节奏型。
- 选段循环、原版与丰富版对比、连接试听、速度调整。
- 本地保存和 JSON 导入导出；响应式布局适配手机、平板。

音色由浏览器合成，并非录音采样。首次播放需要点击按钮。手机和平板应在浏览器内打开，文件预览器可能不支持音频。尚未完成 iPhone/iPad 真机验收。

## 修改与验证

开发时使用 Node.js 18 或更新版本，无第三方依赖。

```sh
npm run build
npm test
```

- `src/app.js`：和声、指法、音频与交互。
- `src/styles.css`：样式与移动端布局。
- `src/template.html`：页面结构。
- `index.html`：生成的单文件离线版，修改源码后重新构建并一同提交。
- `tests/`：和声、音频调度、指法、选段及对比练习的自动检查；不替代真实浏览器试听。
- [新增进行与歌曲候选](docs/progression-candidates.md)：试弹确认后再加入界面。

后续通过 GitHub Desktop 查看改动、提交和推送即可保留修改历史。练习存档只保留在本机浏览器或用户导出的文件里，不随仓库上传。
